# 🦖 Dino Game

A fun, interactive, and responsive **Dino Game** built using **HTML, CSS, and JavaScript**.

The game is inspired by the classic browser dinosaur game and features smooth jumping mechanics, moving obstacles, score tracking, collision detection, and an interactive game-over experience.

---

## 🎮 Features

- 🦖 Interactive Dino character
- 🦘 Jump functionality
- 🌵 Moving obstacles
- 💥 Collision detection
- 🏆 Real-time score tracking
- 🎯 Increasing game challenge
- 🔄 Restart game functionality
- ⌨️ Keyboard controls
- 📱 Responsive design
- ✨ Smooth animations
- 🎨 Clean and modern UI

---

## 🕹️ How to Play

### Keyboard Controls

Press:

**SPACE** → Jump

Avoid the obstacles and try to achieve the highest possible score.

If the Dino collides with an obstacle, the game ends.

Click **Restart** to play again.

## ⚙️ Game Mechanics

### 🦖 Dino Jump

The Dino can jump when the player presses the **Spacebar**.

### 🌵 Obstacles

Obstacles continuously move toward the Dino. The player must jump over them to survive.

### 💥 Collision Detection

JavaScript checks the position of the Dino and obstacles to determine whether a collision has occurred.

### 🏆 Score

The player's score increases as they successfully avoid obstacles.

### 🔄 Restart

After the game ends, the player can restart the game and try to beat their previous score.
